--- /sys.help ---
DETAILED HELP: /sys.help

Command: /sys.help
Aliases: /help
Description: Show this command reference
Category: General Commands
Usage: /sys.help [category] [command]

Examples:
  /sys.help                   - Show main help menu
  /sys.help model             - Show all model commands
  /sys.help model.switch      - Show detailed help for model.switch
  /help all                   - Show comprehensive command list

System Tips:
  • Use category names to see groups of related commands
  • Use specific command names for detailed usage information
  • The 'all' option shows every command in a table format

Use /sys.help sys to see all system commands

--- /sys.quit ---
DETAILED HELP: /sys.quit

Command: /sys.quit
Aliases: /quit
Description: Exit and save configuration
Category: General Commands
Usage: /sys.quit

The quit command safely exits Hi, Ollama! while preserving your:
  • Chat configurations and personas
  • User-defined aliases
  • Global settings (model, context window)
  • Logging preferences

System Tips:
  • All settings are automatically saved before exit
  • Chat histories are preserved in individual files
  • Configuration files are updated with current state

Use /sys.help sys to see all system commands

--- /model.switch ---
DETAILED HELP: /model.switch

Command: /model.switch
Description: Change the current model
Category: Model Management
Usage: /model.switch [model_selection]

Examples:
  /model.switch           - Show available models with selection options
  /model.switch 1         - Select model #1 from the list
  /model.switch llama3    - Select model by name (exact or partial match)
  /model.switch code      - Select model by partial name match

Shows available Ollama models when called without arguments. Accepts model 
selection by number (from displayed list) or by model name (exact or partial match).
The selected model applies globally to all chat sessions.

Requirements:
  • Ollama must be running
  • At least one model must be available

Model Tips:
  • Model selection affects all chats simultaneously
  • Larger models provide better quality but use more resources
  • Use /model.vars to see current model information
  • Socket clients can parse the plain text model list programmatically

Use /sys.help model to see all model commands

--- /model.setctx ---
DETAILED HELP: /model.setctx

Command: /model.setctx
Description: Set max context window size
Category: Model Management
Usage: /model.setctx [context_size]

Examples:
  /model.setctx           - Show current context settings with guidance
  /model.setctx 4096      - Set context to 4096 tokens
  /model.setctx 8192      - Set context to 8192 tokens

Model Tips:
  • Larger contexts use more VRAM and may slow performance

  • Setting applies globally to all chats

--- /chat.twist ---
DETAILED HELP: /chat.twist

Command: /chat.twist
Description: Copy AI response to another chat
Category: Chat Navigation
Usage: /chat.twist [target_chat]

Examples:
  /chat.twist 2           - Send last AI response to chat 2
  /chat.twist             - Send to next available chat

This powerful feature allows continuing conversations across different personas
or contexts by taking the AI's most recent response and using it as a new
prompt in another chat.

Chat Tips:
  • Copies the AI's last response, not your prompt
  • Useful for exploring different perspectives on the same topic
  • Each chat processes the response according to its own persona
  • Creates seamless conversation flow between different contexts

--- /persona.set ---
DETAILED HELP: /persona.set

Command: /persona.set
Description: Set a system prompt at slot 0-9
Category: Persona Management
Usage: /persona.set <slot> <content>

Examples:
  /persona.set 0 You are a helpful coding assistant
  /persona.set 1 Focus on Python best practices
  /persona.set 2 Explain concepts simply

Slots 0-9 are combined to form the complete system prompt sent to the AI.
Slot 0 is typically used for the main persona definition.

Persona Tips:

  • Lower numbered slots are processed first
  • Content can span multiple sentences
  • No quotes needed for multi-word content

DETAILED HELP: /alias.list

Command: /alias.list
Description: List all command aliases
Category: Alias Management
Usage: /alias.list

Shows all available aliases including:
  • User-defined aliases
  • Built-in aliases (help, quit)
  • Target commands for each alias
  • Usage examples

Alias Tips:
  • Built-in aliases are marked differently from user aliases
  • Shows the full command each alias maps to
  • Useful for reviewing your custom shortcuts
  • Helps avoid conflicts when creating new aliases
