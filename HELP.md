PROMPT COMMANDS HELP

The prompt system allows you to save and reuse frequently used prompts or prompt templates. You can store up to 10 numbered prompt slots (0-9) that persist between sessions, making it easy to quickly apply common instructions, writing styles, or analysis frameworks to your conversations. This system helps streamline repetitive tasks and maintain consistency in your interactions with the AI.

PROMPT MANAGEMENT

 /prompt.set   Save a prompt to a numbered slot (0-9)
 /prompt.use   Apply a saved prompt from a slot
 /prompt.list  Display saved prompts by slot number

MORE HELP

 /prompt.help  shows this help screen

Use /sys.help <command> for detailed help on specific commands
Example: /sys.help prompt.set
